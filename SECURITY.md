# Security Policy

## Scope

This repository hosts a static Jekyll site (velkris.red) and two companion
open-source tools:

- **OffsetInspect** — [github.com/warpedatom/OffsetInspect](https://github.com/warpedatom/OffsetInspect)
- **OffsetScan** — [github.com/warpedatom/OffsetScan](https://github.com/warpedatom/OffsetScan)

Security reports for those tools should be filed in their respective
repositories, not here.

## Reporting a vulnerability in this site

If you discover a vulnerability affecting velkris.red itself (e.g. a dependency
with a known CVE, a CI/CD misconfiguration, or a content injection issue):

1. **Do not open a public issue.**
2. Email **security@velkris.red** with a brief description, steps to reproduce,
   and any proof-of-concept.
3. You will receive an acknowledgement within 72 hours.

There is no bug bounty programme. Credit will be given in the changelog for
confirmed and fixed issues.

## Supported versions

Only the latest commit on `main` is actively maintained. No guarantees are made
for historical versions of the site.
