# About

I'm **Velkris**, a cybersecurity practitioner and red team operator. My focus is
offensive security and the defensive tradecraft around it - malware triage,
detection engineering, and understanding exactly where and why a payload gets
caught.

I build open-source tooling for that work. [OffsetInspect](/projects/) and its
native Rust companion [OffsetScan](/projects/) handle detection-boundary and
static analysis - read-only by design, never disabling or reconfiguring endpoint
protection. [NoiseHound](/projects/) and its Rust engine [DeadAir](/projects/)
score BloodHound attack paths by how detectable they are, so an operator can take
the quietest route to an objective instead of just any route.

This site is where I keep original write-ups on how these techniques and
mechanisms actually work - grounded in public research, in my own words.
